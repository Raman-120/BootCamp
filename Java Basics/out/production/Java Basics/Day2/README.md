Student Management System:
<br>
Day2.Student Management System is a simple menu based Management
system that allows users to add, search and display students.
I have used 3 classes, one is Day2.SimpleStudentManagementSystem
that acts as a main class of our program and then I used
Day2.Student class to collect the necessary information of the
student such as student Id, name, email, course and age and
then with the Day2.StudentManagement class I did the necessary
operations such as adding, displaying or searching students
through appropriate methods.
