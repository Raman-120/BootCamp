Product Management System:
<br>
This program demonstrates basic crud operations along
with features such as add product, view all product,
search product by ID, Update product, Delete product,
search product by category and exit. This program uses List
to collect product object and stores them in two different
ArrayList, uses a Product class to set up the properties
of Product object. This program code is long as I have repeated
a lot, but I will make it easier to understand and simple
in future with my knowledge and experience.
